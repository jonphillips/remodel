## Status: exploratory example, not the recommended plan

Jon wants to keep this example to discuss with Wendy. He explicitly rejects its priority weighting: the reduced cleanup run sacrifices daily dish landing and cleanup functionality to accommodate hosting roughly 15–20 times a year.

The enclosed original report and CURRENT_STATE snapshot predate that correction. Their recommendation of the compact island / three angled seats combination is historical and is withdrawn as a preferred overall layout. Three seats remain a comparison, not a chosen reduction from four.

The drawing’s truncated 65-inch cleanup row is not a complete daily cleanup solution. Its 30-inch sink module plus 24-inch dishwasher leave only 11 inches in aggregate for everything else. Retaining a fixed wall face did not justify dropping the existing bent cleanup frontage from the program.

Next work must start with usable daily cleanup, chef prep, range landing and circulation. Guest seating and the occasional buffet must adapt to that baseline. Preserve this example unchanged for comparison.
